# Akash R Portfolio

A responsive developer portfolio built with Vite, React, Tailwind CSS, and Framer Motion.

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run lint
npm run build
npm run preview
```

## Content Editing

Portfolio content is centralized in:

- `src/data/portfolioData.js`

Update project links, technology tags, and section copy there without changing layout components.
